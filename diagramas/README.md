# Diagramas del Sistema de Gestión Académica

Esta carpeta contiene los modelos gráficos elaborados para representar la arquitectura propuesta del SGA.

Los diagramas incluyen:

- Arquitectura general.
- Casos de uso.
- Vista lógica de componentes.
- Modelo de despliegue.
- Modelo conceptual de datos.
- Diagrama de secuencia del proceso de matrícula.
