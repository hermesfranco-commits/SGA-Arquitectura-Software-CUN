# Sistema de Gestión Académica (SGA)

## Descripción

Proyecto académico de diseño y modelado de una arquitectura de software para un Sistema de Gestión Académica, desarrollado en la asignatura Arquitectura de Software de la CUN.

## Objetivo

Proponer una solución que permita centralizar la información académica de estudiantes, docentes, programas, asignaturas, grupos, matrículas y calificaciones.

## Arquitectura propuesta

Se seleccionó una arquitectura en capas con enfoque de monolito modular, organizada en:

- Presentación.
- Aplicación.
- Dominio o lógica de negocio.
- Infraestructura y persistencia.

## Actores

- Administrador.
- Coordinador académico.
- Docente.
- Estudiante.

## Modelos del sistema

Los diagramas se encuentran en la carpeta `diagramas`:

1. Arquitectura general.
2. Casos de uso.
3. Vista lógica de componentes.
4. Modelo de despliegue.
5. Modelo conceptual de datos.
6. Diagrama de secuencia de matrícula.

## Uso de inteligencia artificial

Se utilizaron ChatGPT y Google AI Studio (Gemini) como herramientas de apoyo para analizar, revisar y mejorar la propuesta arquitectónica. Las recomendaciones fueron evaluadas antes de incorporarlas al diseño.

## Alcance

Este proyecto corresponde a una propuesta de diseño y modelado arquitectónico. No representa un sistema implementado ni desplegado.
